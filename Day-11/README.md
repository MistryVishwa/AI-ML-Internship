# Day 11 - Prediction App

## Task Description
Create a simple Python program where users enter study hours and receive a predicted score. 

## Expected Outcome
Working prediction program.

## Folder Structure
- `prediction_app.py`: The main python script containing the linear regression model and command-line interface.
- `requirements.txt`: Python dependencies required to run the script.

## Setup Instructions
1. Ensure you have Python installed on your system.
2. Open a terminal in the `Day-11` directory.
3. Install the dependencies by running:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   python prediction_app.py
   ```
5. Follow the on-screen prompt to enter the number of study hours and get the predicted score.
