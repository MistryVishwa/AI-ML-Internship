# Python Basics Toolkit

## Day 2 – Codomax Digital Solutions Internship

This project demonstrates the fundamental concepts of Python programming through a menu-driven command-line application.

## Topics Covered

- Variables
- Data Types
- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Conditional Statements
- Loops
- Functions
- Modular Programming

Clone repository


Open folder

```

```
