# Day 3 – NumPy Fundamentals

## Project Overview

This project is part of the **Codomax Digital Solutions AI/ML Internship**.

The objective of Day 3 is to understand the fundamentals of **NumPy**, the core numerical computing library in Python. The project demonstrates array creation, indexing, slicing, mathematical operations, statistical functions, reshaping arrays, and a practical example using student marks.

---

## Topics Covered

- Introduction to NumPy
- Creating 1D and 2D Arrays
- Array Properties
- Array Indexing
- Array Slicing
- Mathematical Operations
- Statistical Functions
- Reshaping Arrays
- Transpose and Flatten
- Real-world Array Calculations

## Installation

Clone the repository

```bash
git clone https://github.com/MistryVishwa/AI-ML-Internship.git
```

Go to the project folder

```bash
cd AI-ML-Internship/Day-03
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python main.py
```
