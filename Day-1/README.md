# Day 1 – Environment Setup

## Objective

The objective of Day 1 is to prepare the complete development environment for the AI & ML Internship by installing the required software, verifying the setup, and running the first Python program.

---

## Program Name

**Environment Setup Verification**

This Python program verifies that the development environment is correctly configured for AI & Machine Learning development.

---

## Features

- Displays internship information
- Displays system information
- Shows Python version
- Shows operating system details
- Confirms installation of:
  - Python
  - VS Code
  - Git
  - Jupyter Notebook
- Prints a confirmation message indicating that the environment is ready

---

## Technologies Used

- Python 3
- VS Code
- Git
- Jupyter Notebook
